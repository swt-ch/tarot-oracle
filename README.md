# 🔮 Tarot Oracle

An AI-powered tarot reading app built with React + Claude API.

## Deploy to Vercel (Free, 5 minutes)

### Step 1 — Upload to GitHub
1. Go to [github.com](https://github.com) and sign in (or create a free account)
2. Click **"New repository"** → name it `tarot-oracle` → click **Create**
3. Upload all these project files to the repository

### Step 2 — Deploy with Vercel
1. Go to [vercel.com](https://vercel.com) and sign in with GitHub
2. Click **"Add New Project"**
3. Select your `tarot-oracle` repository
4. Click **Deploy** — that's it!

Vercel will give you a live URL like:
`https://tarot-oracle-yourname.vercel.app`

Share that link with anyone — no installation needed!
